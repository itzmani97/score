# Score Express Inc Website

Professional trucking company website for Score Express Inc, Brantford, Ontario.

## Quick Start

Open `index.html` in a browser to view locally.

## Deployment to GitHub Pages

1. Create a new GitHub repository
2. Push these files to the `main` branch
3. Go to Settings → Pages
4. Source: `main` branch, `/ (root)`
5. Save - your site will be live at `https://[username].github.io/[repo-name]`

## Form Setup

1. Go to [formspree.io](https://formspree.io) and create a free account
2. Create a new form
3. Copy your form ID (the number in your form URL)
4. Replace `YOUR_FORM_ID` in `index.html` with your actual form ID

## Customization

- **Phone number**: Search for `(519) 800-1234` in `index.html`
- **Email**: Search for `info@scoreexpress.ca` in `index.html`
- **Logo**: Replace the emoji logo in the header with an `<img>` tag
- **Colors**: Edit CSS variables in `styles.css`
